# Projeto de Circuitos Digitais em Logisim

Este projeto foi desenvolvido utilizando o Logisim e reúne a implementação de diversos componentes fundamentais da lógica digital, incluindo somadores, subtratores, comparadores e multiplexadores. O circuito principal integra esses módulos para demonstrar operações aritméticas e lógicas realizadas a partir de portas básicas, como AND, OR, XOR e NOT.

O objetivo do projeto é aplicar conceitos de Arquitetura e Organização de Computadores, Eletrônica Digital e Sistemas Computacionais, explorando o funcionamento interno de circuitos combinacionais e a construção de componentes mais complexos a partir de elementos básicos.

## Componentes implementados

* Somador completo (Full Adder)
* Subtrator completo
* Comparador lógico
* Multiplexador
* Circuito principal integrando os módulos

## Tecnologias utilizadas

* Logisim
* Portas lógicas AND, OR, XOR e NOT
* Circuitos combinacionais

## Objetivo

O projeto foi desenvolvido para reforçar o entendimento sobre representação binária, operações aritméticas digitais, propagação de sinais e modularização de circuitos lógicos.
